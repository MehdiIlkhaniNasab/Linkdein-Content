# بادبان (Badban by Ronagh) — برند شخصی در لینکدین

**بادبان** چهارمین ابزار خانواده رونق است: قطب‌نما جهت را می‌دهد، سکان هدایت می‌کند، فانوس مسیر را نشان می‌دهد و **بادبان برند شخصی را به حرکت درمی‌آورد**.

| ابزار | نقش | آدرس |
|---|---|---|
| **قطب‌نما** | کیورد کلاسترینگ، پیلارها و تقویم محتوا | `/seo/cluster/` |
| **سکان** | اکشن پلن، اجرای کارها، سنجش اثر | `/seo/plan/` |
| **فانوس** | گزارش ماهانه کارفرما | `/seo/report/` |
| **بادبان** | برند شخصی در لینکدین: استراتژی، تولید، طراحی، انتشار خودکار، آنالیتیکس | `/seo/brand/` |

افزونه وردپرس مستقل (بدون Composer، بدون CDN)، با ورود جداگانه و تم **بنفش الماسی**.

## امکانات

| بخش | جزئیات |
|---|---|
| استراتژی برند | جایگاه، مخاطب هدف (انگلیسی و فارسی)، اهداف، شواهد، صدای برند، نمونه نوشته‌ها، عبارت‌های ممنوع، ۷ ستون محتوا با وزن هدف (استراتژی، تکنیکال، محتوا، آف‌پیج، کار تیمی، کیس استادی، رشد حرفه‌ای) |

| دو زبان | انگلیسی برای مخاطب بین‌المللی و فارسی؛ نسخه فارسی بازنویسی بومی است نه ترجمه، و در روز جدا منتشر می‌شود |
| قالب‌ها | متنی، **کاروسل PDF** (۶–۱۰ اسلاید)، کارت تصویری (بدون هزینه تولید تصویر)، نظرسنجی |

| استودیو | پیش‌نمایش شبیه لینکدین (با «…بیشتر»)، ویرایشگر اسلاید، بررسی کیفیت با امتیاز، ذخیره خودکار |
| ناشناس‌سازی | نام، دامنه، برند و رقبای همه پروژه‌های سکان، قطب‌نما و فانوس قبل از ارسال به هوش مصنوعی حذف می‌شوند و اگر در پست بمانند انتشار متوقف می‌شود |

## نصب

1. `bin/build-zip.sh` (یا پوشه `badban` را زیپ کنید) و در وردپرس › افزونه‌ها › افزودن › بارگذاری نصب کنید؛ بهترین حالت: روی همان وردپرس سکان، قطب‌نما و فانوس.
2. برنامه لینکدین: developer.linkedin.com › Create app › Products: **Share on LinkedIn** و **Sign In with LinkedIn using OpenID Connect** › Redirect URL را از تنظیمات بادبان کپی کنید.
3. **مسیر شبکه** (سرور در ایران): پروکسی وردپرس (`WP_PROXY_HOST`) با حالت «هوشمند»، یا رله کلادفلر `badban/relay/cloudflare-worker.js` روی زیردامنه خودتان.
4. در «استراتژی برند» نمونه نوشته‌ها و شواهد را کامل کنید، در «بانک ایده» «جمع‌آوری ایده‌های تازه» و در داشبورد «برنامه‌ریزی و نوشتن ۲ هفته آینده» را بزنید.
5. کران سرور برای انتشار دقیق: `*/5 * * * * wget -q -O - https://your-site.com/wp-cron.php?doing_wp_cron`

## محدودیت‌های لینکدین

- انتشار روی **پروفایل شخصی** با محصولات self-serve بالا ممکن است؛ توکن ۶۰ روزه است و تمدید یک کلیک.
- آمار پروفایل شخصی از طریق API فقط به شرکای تأییدشده داده می‌شود؛ بادبان فایل Export خود لینکدین را می‌خواند.

## ساختار کد

```
badban/
  badban.php                 بارگذاری، ثابت‌ها
  inc/core/                  helpers، jalali، settings، network (پروکسی/رله)، install (جدول‌ها + کران)
  inc/models/                posts، ideas، stats
  inc/connectors/            llm (سکان/GapGPT/Anthropic)، linkedin (OAuth، Posts، Documents، Images، Comments)
  inc/engine/                brand، sources (برداشت ایده + ناشناس‌سازی)، writer، quality، planner، publisher، analytics
  inc/rest.php               API اپ (badban/v1)
  inc/app/                   router (/seo/brand/)، ui، actions
  templates/app/             shell، login، report و views
  assets/js/slides.js        رندر اسلاید روی Canvas + نویسنده PDF و PPTX بدون کتابخانه
  assets/js/app.js           استودیو، برنامه‌ریز، ایده‌ها، آنالیتیکس
  relay/cloudflare-worker.js رله لینکدین برای سرورهای ایران (Cloudflare Worker)
```
